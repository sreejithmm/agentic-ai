# Chatbot Agent

This is the first step of a customer support agent for the Malayalam film
*Drishyam*. It sends one question at a time to the shared Azure OpenAI client.
The prompt contains a small local knowledge base, so this version has no search
tool and does not ask the model to rely on its general knowledge.

## Run It

Run these commands from the `agentic-ai` project root:

```bash
source .venv/bin/activate
```

Activates the workspace virtual environment.

```bash
python -m chatbot.main
```

Starts the interactive support loop. The Azure settings must be exported first;
the shared client reads `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_ENDPOINT`, and
`AZURE_OPENAI_DEPLOYMENT` from the environment.

Type `exit`, `quit`, or `q` to stop the loop.

The chatbot keeps the questions and answers from the current run in memory and
includes them in later prompts, so follow-up questions can refer to earlier
messages. The history is cleared when the process stops.

The command-line interface uses Rich to display a styled agent header, colored
question prompts, bordered agent responses, and a usage summary panel.

Every question exposes Azure Responses API's `web_search_preview` tool to the
model. The model decides whether to use it: it answers from the local knowledge
base when possible and searches for missing or current information. The selected
Azure deployment and API version must support this tool. Web results can add
latency and usage charges, and the answer is still generated by the deployed
model.

When the conversation ends, the agent prints the accumulated input tokens,
output tokens, total tokens, and an approximate cost. The estimate uses
`$0.075` per million input tokens and `$0.30` per million output tokens; update
these values in `main.py` to match the deployed Azure model's pricing.

Example questions:

```text
Who plays Georgekutty?
What is the central conflict?
Who directed the film?
```

## Validate Without Calling Azure

```bash
python -m py_compile chatbot/main.py common/io_utils.py common/azure_openai_client.py
```

Checks this agent and the shared client for Python syntax errors without making
an Azure request.

## Files

- `main.py` contains the local knowledge base, grounded prompt, and question loop.
- `../common/io_utils.py` contains reusable Rich terminal presentation helpers.
- `README.md` documents this agent's purpose and commands.
- `__init__.py` marks the folder as a Python package.

Shared Azure configuration, dependency installation, security guidance, and
workspace conventions are documented in the root [`README.md`](../README.md).
